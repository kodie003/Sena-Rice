# Sena Rice

Website for Sena Rice — premium long-grain rice grown on the delta of the Volta River, Ghana.

Static HTML/CSS/JS, deployed on Vercel.

## Editing

Shared header, footer and page bodies live in `_build/`. After editing them, rebuild the pages:

```sh
python _build/build.py
```

`css/styles.css` and the files in `js/` can be edited directly.
